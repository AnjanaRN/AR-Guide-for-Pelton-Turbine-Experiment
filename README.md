# AR Guide for Pelton Turbine

An Augmented Reality (AR) application developed to provide an interactive and visual learning experience for the **Pelton Turbine Experiment**.

The application allows users to scan a marker or QR code and visualize the Pelton Turbine model in Augmented Reality. Users can explore different machine parts and access information about their components and functionality.

## Features

* Augmented Reality visualization of the Pelton Turbine
* Interactive exploration of machine components
* Information about different turbine parts
* Marker/QR-based AR experience
* Educational and user-friendly interface

## Technologies Used

* **Unity 6**
* **AR Foundation**
* **ARCore**
* **C#**
* **Blender**
* **Visual Studio Code**

## How to Run

1. Clone this repository.
2. Open the project using **Unity 6**.
3. Make sure the required AR packages are installed.
4. Switch the platform to **Android**.
5. Connect an ARCore-supported Android device or build the application.
6. Launch the application and scan the supported marker/QR code to view the Pelton Turbine in AR.

## Purpose

This project was developed as part of an internship to explore the use of **Augmented Reality in education and engineering visualization**. The aim is to make the Pelton Turbine experiment easier to understand through interactive 3D visualization.
